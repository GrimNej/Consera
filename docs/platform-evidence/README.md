# Platform evidence

This directory contains sanitized, reproducible command output and fixtures for executable platform-contract tests. Never place a secret, complete connection string, cookie, token, raw production data, or build log containing a secret here.

Each artifact name uses `YYYY-MM-DD_HHMM_H-XX_check-name.md` and records command, expected result, observed result, timestamp, service/version identifiers, and request IDs only when sanitized.
